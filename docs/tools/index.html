12张行动工具卡

每张卡围绕一个实际任务：核实事实、理解关系、确定权责、采取行动和反馈修正。它们是可编辑、可打印的思考支架，不是心理测量、成长评分或诊断工具。

**重要**：网页不收集、不上传、不自动保存填写内容。涉及隐私、风险或正式争议的资料，请使用安全且符合法律和学校规定的方式存放。
TOOL 01

事件判断卡

当你只有“我不适合”这类模糊感受时，把一个问题变成可分析的行动事件。

TOOL 02

SSCM五维观察卡

用C、N、R、V、A描述某件事的状态，不做总分或人格评级。

TOOL 03

社会支持与公开入口地图

避免过度依赖单一熟人，辨认能实际回应某项需要的正式渠道。

TOOL 04

规则查证卡

用于选课、奖助、评优、报名、实习或学籍等具有正式程序的事项。

TOOL 05

求助与专业沟通卡

把笼统请求变成对方可以处理的问题，减少沟通负担。

TOOL 06

小组任务与权责约定卡

让共同任务可交付、可检查，也允许成员提出困难和调整安排。

TOOL 07

边界与拒绝沟通卡

用于时间、借用、亲密关系、隐私与临时加码等情境。

TOOL 08

冲突澄清与修复卡

先区分事实、影响和需求，再决定继续沟通、调解或减少往来。

TOOL 09

成果与真实贡献记录卡

为科研、竞赛、社团、求职记录能复查的任务贡献，不把头衔当作证据。

TOOL 10

多路径选择比较卡

用于转专业、升学、职业、组织参与及重大时间承诺。

TOOL 11

权益事件与求助记录卡

记录与规则、评分、骚扰、劳动或网络风险相关的事实和已采取的正当措施。

TOOL 12

月度关系与行动复盘卡

在长期成长中观察实际变化，不给自己贴“成熟度”标签。
