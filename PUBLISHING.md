# GitHub Pages deployment / GitHub Pages 部署

**Repository:** https://github.com/drizzletown/campus-socialization-guide

**中文 / Chinese:** https://drizzletown.github.io/campus-socialization-guide/

**English:** https://drizzletown.github.io/campus-socialization-guide/en/

The complete static site is contained in `docs/`. Configure GitHub **Settings → Pages → Deploy from a branch**, branch `main`, folder `/docs`. The file `docs/.nojekyll` is included. No custom domain, server, database or API key is required.

完整网站位于 `docs/`，可使用 GitHub Pages 的 `main` 分支 `/docs` 目录发布。无需运行服务器或配置数据库。

After publishing, verify home pages in both languages, chapter 1 and 50, language switching from a chapter, search, scenario exercises, worksheets and mobile layout. Confirm the Pages workflow is successful in GitHub Actions.

发布后，请同时检查中英文首页、首末章、章节间语言切换、检索、情境练习、行动工具和手机屏幕阅读。
